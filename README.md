# Dashboard de Ventas

## Objetivo

Analizar el comportamiento comercial de una empresa mediante indicadores clave de ventas.

## Herramientas utilizadas

- Power BI
- Power Query
- DAX

## Indicadores principales

- Ventas Totales
- Número de Ventas
- Clientes Únicos
- Ticket Promedio
- Ventas por Mes
- Top Productos
- Top Clientes

## Principales hallazgos

El dashboard permite identificar tendencias de ventas, productos con mejor desempeño y clientes más importantes.
